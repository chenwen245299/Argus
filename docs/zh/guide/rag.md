# RAG 与全库问答

这一页介绍两件相互独立的事：

- **RAG / 向量化** —— Argus 会用你选择的embedding模型把论文切块、向量化，在文献库文件夹里构建一份**本地**向量索引，[向量图谱](/zh/guide/embedding-map)就是用这份索引画出来的。
- **智能问答** —— 对整个文献库提问，AI 会自己调用工具查阅论文、笔记和素材。智能问答不使用向量索引，没有配置RAG也能正常使用。

## 工作原理

1. **切块(Chunking)** —— 论文全文按段落感知切分为带可配置重叠的文本块。
2. **向量化(Embedding)** —— 使用用户选择的embedding模型为每个块生成对应向量。embedding模型可以来自 OpenAI 或任意 OpenAI 兼容接口的供应商(如 OpenRouter)，也可以用 Ollama 的本地模型；Anthropic 不提供embedding接口，不能用于向量化。
3. **存储** —— 向量存入文献库文件夹内的本地 SQLite 向量表(`vectors.sqlite`)。除了embedding请求本身，数据不会离开本地。
4. **绘图** —— [向量图谱](/zh/guide/embedding-map)把这些向量投影到二维平面，主题相近的论文会聚在一起。


## 配置RAG

### 配置RAG参数

在使用RAG前，用户需要先在 **设置 → AI 随航 → RAG / 向量化** 中配置对应的RAG参数，包括选择embedding模型、块大小、重叠大小等。embedding模型部分只有当配置的AI供应商中存在embedding模型时服务才可用。

<Media src="/media/1783335689002.png" caption="使用RAG之前需要配置对应的参数，包括embedding模型、分块大小和重叠大小等" />

### 构建向量索引

配置好RAG参数后，用户既可以在论文列表这里通过右键菜单栏为单篇论文构建向量索引（也可以选中多篇论文后右键选择「加入向量库」批量构建），也可以在左侧文献分类中通过右键菜单栏构建整个分类下的论文的向量索引。

<Media src="/media/1783335850750.png" caption="构建单篇论文的向量索引" />

<Media src="/media/1783335952643.png" caption="构建整个分类下的论文的向量索引" />

构建向量索引的进度会实时显示在中间栏的上方。

<Media src="/media/1783336073239.png" caption="向量索引的构建进度会实时显示" />

如果想一次性处理整个文献库，可以打开 **设置 → AI 随航 → RAG / 向量化**，点击「同步缺失」为所有尚未向量化的论文构建索引，中途停止后再点一次即可从断点继续。切换embedding模型后，需要点击「完整重建」重新处理所有论文。

向量化只针对论文，只在以上这些地方进行。素材库不做向量化；智能问答窗口里也没有向量化按钮，不需要为了智能问答而向量化论文。

## 智能问答

智能问答的入口在 **AI 随航 → 智能问答**，点击后即会通过独立窗口显示对话界面，用户可以在此输入问题并进行提问。

<Media src="/media/1783336159510.png" caption="智能问答入口" />

智能问答只有一种模式，不需要选择知识来源，直接提问即可，需要查什么由AI自己决定：

- **AI自己查文献库** —— 模型会调用 Argus 的文献库工具：浏览你的分类、查找论文、阅读论文全文、笔记和高亮、查看 PDF 页面（需要支持视觉的模型）、搜索素材库、打开画布和以往的对话记录，也可以调用你接入的其他 MCP 服务器。它在论文内容里按关键词搜索，查素材则用 `search_snippets` 工具按关键词匹配素材原文、备注、来源论文标题和标签，都不依赖向量索引。每一步查了什么都会随回答一起显示。
- **与文献库无关的问题** —— 翻译、写作、常识等问题，模型会直接回答，不去查文献库。

<Media src="/media/library-rag-chat.mp4" caption="对整个文献库提问" />

消息输入框下方的「工具设置」按钮用于设置工具调用次数上限，以及要接入哪些 MCP 服务器；当前对话的上下文缓存处于保温状态时，这个按钮上会显示一个呼吸的小圆点。

以前版本的对话记录都会保留，其中保存的来源和论文标记照常显示。

### 固定文献

想让对话围绕某几篇论文展开，可以点击消息输入框下方「工具设置」旁的图钉按钮，打开「固定文献」窗口：在「未固定」标签页中按标题、作者或年份搜索，点击论文即可固定；「已固定」标签页列出已固定的论文，点击即可取消固定。

固定之后，标题栏会显示「已固定 N 篇」，旁边的编辑按钮可以随时调整。此后模型会把每个问题都当作关于这些论文的问题，自己去阅读它们，可以帮助用户快速比较不同论文之间的异同。固定文献按对话保存，每个对话最多固定 50 篇。固定的论文如果之后被删除或改名，就不会再发给模型；「已固定」标签页会提示有几篇已不在文献库里，可以一键移除。

在画布中也可以固定文献：右键论文节点（或框选后右键），选择「固定到智能问答」，即可把论文固定到智能问答当前打开的对话里，因此需要先打开智能问答窗口。

<Media src="/media/library-chat.mp4" caption="在一个对话里同时比较多篇论文的异同" />

### 不支持工具调用时

当问题无法通过文献库工具处理时，Argus 会按普通对话回答，并在回答里用一行提示说明原因。以下情况会这样处理：

- 模型不支持工具调用：Anthropic 格式的供应商、Kimi Code、Ollama 原生接口、模型目录标明不支持工具的模型（如阶跃星辰的 step-audio-r1.5），或者服务商拒绝了工具参数；
- 开启了 DeepSeek 的联网搜索：DeepSeek 的联网搜索不能和文献库工具同时使用，想让模型查文献库时关掉联网搜索即可；
- 使用阶跃星辰的语音模型并开启了「语音回复」。

这类回答中，如果对话固定了文献，模型会拿到固定文献的内容，这些文献也会列在回答的来源里；没有固定文献时，模型直接回答，不查阅文献库。想让模型自己查文献库和素材库，换用支持工具调用的模型即可（如 DeepSeek、通义千问，或 OpenRouter 上的多数模型）。
