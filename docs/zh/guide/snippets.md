# 素材库

素材库是一个独立于论文之外的收集箱，用来存放用户阅读论文时的一些摘录，以便后续使用。素材可以按关键词搜索，[智能问答](/zh/guide/rag)里的AI也能自己查阅素材库，方便用户写论文时快速查找和引用。

## 它能做什么

- **随手收集** —— 把有价值的引文、片段、想法存进素材库。
- **快速查找** —— 在素材库界面按关键词搜索素材；在[智能问答](/zh/guide/rag)里提问时，AI 也会自己搜索素材库。
- **不需要向量化** —— 素材不做向量化，也不用为它配置RAG。智能问答里的AI用 `search_snippets` 工具按关键词查找素材，匹配素材原文、备注、来源论文标题和标签。
- **与论文分离** —— 素材库和文献库互不干扰,专门服务于写作引用与灵感整理。

## 存储方式

素材以文件形式存放在文献库文件夹的 `snippets/` 目录下，和论文一样是本地、可迁移的。
